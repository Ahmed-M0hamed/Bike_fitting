
Computer Vision project: Real-Time Bike Fitting using Keypoint Detection 🚴‍♂️💻
This project started from a personal problem — improving my riding posture and bike position.
I built a real-time system that analyzes rider posture using a custom-trained keypoint detection model and provides instant biomechanical feedback based on body angles.

🔹 Workflow

Recorded bike riding videos
Wrote a Python script to extract frames automatically
Annotated the dataset using Roboflow
Trained a custom YOLO11 keypoint detection model
Built a real-time evaluation pipeline using Python and OpenCV
🔹 The system can

✅ Detect rider keypoints in real time
 ✅ Draw posture lines and joint angles
 ✅ Calculate fitting angles automatically
 ✅ Provide posture feedback based on the measured angles

🔹 libraries 
Python • OpenCV • YOLO11 • NumPy • Roboflow
This project helped me combine:
Computer Vision
Deep Learning
Geometry & angle calculations
Real-time video processing
Practical sports analytics
